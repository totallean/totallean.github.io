# totallean.github.io

Portfolio site: plain HTML, CSS and a little JS, served by GitHub Pages.

- Content and translations: `assets/js/main.js` (`STRINGS`); links and contacts: `CONFIG` at the top of the same file.
- Screenshots: `assets/img/`.
- Local preview: `python3 -m http.server 8766` in this folder, then open http://127.0.0.1:8766.
