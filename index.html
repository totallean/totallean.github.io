Spectrum Forge

An incremental game on Roblox: forge glowing constructs from nine colors, power up your Ring and send your Ghost to fight while you are away.

  • Nine server services behind a single bootstrap, with a typed network contract and one economy config for all balance math.
  • Profile saving with a write queue, session locking and BindToClose; offline income computed on join.
  • Spectrum Wheel crates with odds shown in game, a construct builder with color sets, and arena battles against Ghosts.
  • Five game passes and four developer products, a step-by-step tutorial and RU/EN localization chosen from the player's locale.

Physics · Camera · Networking

Web Swing

Spider-Man style web swinging: hold to swing, zip to a point, reel in, jump off with momentum.

  • Pendulum physics on top of Roblox physics: the rope constraint corrects velocity every step instead of teleporting the character.
  • Anchor selection like the console games: an ideal point ahead and above is projected onto the nearest facade, so arcs run along the street.
  • Game feel: body aligned to the rope, arm IK toward the web, speed-based FOV, camera shake, wind streaks.
  • Webs replicate to everyone with server validation; a server-timed ring race feeds a global leaderboard.

NPC AI · Pathfinding · UX

The Stalker

A stealth horror NPC that sees, hears and hunts you through a dark maze. Find the keys, hide in lockers, escape.

  • Perception: view cone, line of sight, lighting, flashlight and crouching; awareness builds up gradually instead of instant detection.
  • Hearing from the speed the server measures, not from what the client claims.
  • Six-state AI (patrol, investigate, search, chase, extract, attack) on PathfindingService with async paths and stuck recovery. If it sees you hide, it pulls you out.
  • Main menu with a live 3D cover shot, a game-over screen, server-driven respawns and Studio-only dev tools for automated QA.

Tycoon · Economy · Monetization

Butter Squish Tycoon

A factory tycoon: butter sticks leave the extruder, get stamped and coated in up to five layers of wax, then sell at the collector.

  • Content-driven design: every station, button and price comes from one config, so a new production step is a single table entry.
  • Six plots with claim pads, purchase buttons that pop in with tweens, belt boosts, rebirths, server-wide announcements and a leaderboard.
  • Achievements with rewards and a collection bonus, a first-time-user tutorial, and a shop with game passes and developer products.
  • Every remote is checked against a declared argument schema with per-remote rate limits; saves use session locking, autosave and BindToClose.
